# Contributing

Read README and AGENTS.md, set up JDK 17 / SDK 34, and keep changes focused. Describe behavior, validation and whether it was tested on a device. Follow the backend README for local catalog work.

Never submit keys, unreviewed APK URLs, fabricated confirmations or cloud AI presented as offline inference. Include tests for changes to transaction integrity, receipt attribution and release validation. Keep source and real-versus-mock documentation consistent.
