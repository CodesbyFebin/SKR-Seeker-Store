# Seeker Store

Native Android discovery, reviewed devnet endorsement transactions, offline Qwen inference and independently installable utilities.

## Utility expansion

Nine separate utility source modules are implemented. See [utilities/README.md](utilities/README.md) for exact capabilities and remaining work, and [utilities/catalog.json](utilities/catalog.json) for package IDs. All utility APK builds and device checks are pending. CI will compile/lint the store and utilities and expose artifacts when successful. Maps, camera, weather, translation, fitness, messaging, browser and scanner remain unimplemented. This is a partial implementation of the full requested suite; source presence is not a successful build or device test.

The store does not replace Google Play or the Solana dApp Store. No exhaustive audit supports the claim that all existing store apps lack native/offline/privacy features. No utility has SKR rewards, Genesis/TEEPIN verification or Seed Vault integration. Only independently reviewed APK metadata can enable installer downloads.
