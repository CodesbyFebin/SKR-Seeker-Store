# Seeker Store

Native Android discovery, reviewed devnet endorsement transactions, offline Qwen inference and independently installable utilities.

## Utility expansion

Eighteen separate utility source modules are implemented. See [utilities/README.md](utilities/README.md) for exact capabilities and remaining work, and [utilities/catalog.json](utilities/catalog.json) for package IDs. The store and all 18 utility APKs passed CI build/lint, applicable unit tests and signature/package/digest checks at commit 9bdf4a9. All phone runtime checks remain NOT_RUN. See QUALIFICATION.md for the successful run and 19 APK downloads; utilities/README.md records per-feature scope. The suite includes CameraX capture, cached weather, foreground sensor steps, manual LAN encrypted chat, offline Qwen translation, private GeckoView browsing and cached road-path calculation. These are limited first implementations, not feature parity with mature consumer apps. Live camera document scanning, full navigation and automatic nearby discovery remain pending. Source presence is not a successful build or device test.

The store does not replace Google Play or the Solana dApp Store. No exhaustive audit supports the claim that all existing store apps lack native/offline/privacy features. No utility has SKR rewards, Genesis/TEEPIN verification or Seed Vault integration. Only independently reviewed APK metadata can enable installer downloads.
