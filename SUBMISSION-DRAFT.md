# Seeker Store

**Tagline:** Mobile discovery, reviewed endorsements, and offline recommendations.

**Description:** Seeker Store is a Kotlin / Compose curation layer over the Solana dApp Store, with a dedicated DePIN view and an offline Qwen recommender. This MVP models SKR-weighted curation with clearly labeled local scores and 0.001 SOL devnet endorsement transfers through Mobile Wallet Adapter. Exact-message review, encrypted receipts and Android Keystore signatures make each endorsement reviewable; actual SKR staking, Genesis ownership, Guardian governance and TEEPIN attestation are future integrations.

**Category:** Tools / DePIN

**SKR integration:** Mock ranking and planned synergy bonus display only. No SKR token transaction or staking program integration is present. Do not claim actual staked endorsements or mobile identity-bound curation.

The debug APK is built and unit-tested. Update this draft after wallet and offline inference device verification. Attach the genuine demo video and measured evidence before submission. Do not use “finally shipped” until phone verification is complete.
